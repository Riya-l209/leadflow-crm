# LeadFlow CRM 🚀

A lightweight Lead Management System built with React + Node.js + Express + Prisma.

---

## 📌 Features

- Add & manage leads
- Track lead status (New, Contacted, Qualified, etc.)
- Add discussions per lead
- Set follow-up reminders
- View timeline of interactions

---

## 🛠 Tech Stack

- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: Prisma ORM
- Language: TypeScript

---

## 🚀 How to Run Locally

### 1. Clone repository

git clone <repo-url>


### 2. Backend setup

cd server
npm install
npx prisma generate
npm run dev


### 3. Frontend setup

cd client
npm install
npm run dev
